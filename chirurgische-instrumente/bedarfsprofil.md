# Bedarfsprofil – Fertigungsunternehmen Chirurgische Instrumente (Europa)

Kunde / Projekt:        Zielliste „Hersteller chirurgischer Instrumente in Europa"
Referenz-Unternehmen:   KLS Martin / Gebrüder Martin, ASANUS Medizintechnik,
                        Sprenger Medizintechnik, DIMEDA Instrumente
                        → alle aus dem Cluster Tuttlingen (BW), Weltzentrum für chirurgische Instrumente.

Problem / Bedarf:       Gesuchte Firmen sind selbst die Hersteller/Fertiger von
                        chirurgischen Instrumenten (Scheren, Pinzetten, Klemmen,
                        Nadelhalter, Raspatorien, Knochenchirurgie, Mikrochirurgie,
                        Wiederverwendbare Edelstahl-/Titaninstrumente etc.).

Ziel-Branchen / Sub-Sektoren:
  - Allgemeinchirurgische Handinstrumente (Edelstahl)
  - Mikrochirurgie / Ophthalmologie / HNO / Dental-Chirurgie
  - Orthopädie / Knochenchirurgie / Implantat-begleitende Instrumente
  - OEM-/Lohnfertiger für chirurgische Instrumente (Schleifen, Polieren, Laserbeschriftung)
  - Dental-/Veterinär-Instrumente (wenn chirurgisch)

Firmengröße:            KMU bis Mittelstand (ca. 5–500 MA), inhabergeführte
                        Manufakturen typisch.

Region / Land:          Europa — Schwerpunkt DE (Tuttlingen/BW), dazu UK (Sheffield),
                        FR, IT, ES, CH, AT, PL, BENELUX, Skandinavien, Osteuropa.

Bedarfs-Signale:        „chirurgische Instrumente", „surgical instruments
                        manufacturer", „Medizintechnik Instrumente", Edelstahl/Titan,
                        wiederverwendbar, CE/MDR, ISO 13485, Tuttlingen-Sitz,
                        OEM/Eigenmarke, Instrumenten-Schleiferei.

Ausschlusskriterien:    Reine Händler/Distributoren ohne Fertigung; Hersteller von
                        Einmal-Verbrauchsmaterial ohne Instrumente; reine Implantat-
                        Hersteller ohne Instrumente; Großgeräte/Bildgebung; Möbel;
                        außereuropäische Sitze (Sialkot/PK, USA) ohne EU-Fertigung;
                        reine Aufbereitung/Sterilisation-Dienstleister.
