# Bedarfsprofil – MK Kögel Werkstücklogistik

Kunde / Produkt: MK Kögel GmbH (Oberderdingen). Werkstücklogistik –
teilespezifische **Werkstückträger**, Reinigungsträger (Techtray), hygienischer
Teiletransport (Puros), Transport-/Lager-/Kommissionierbehälter, Haltesysteme
(RK Clip, TechVarioSpin). Schwerpunkt: industrielle Bauteilereinigung,
technische Sauberkeit, Reinraum & Medizintechnik, Teile aus Stahl/Edelstahl.

Problem, das es löst: Bauteile müssen entlang der Intralogistik-Kette (Reinigung →
Transport → Lagerung → Kommissionierung → Montage) beschädigungsfrei, prozess-
sicher und sauberkeitskonform gehandhabt werden. Werkstückträger fixieren,
schützen und durchlaufen Reinigungs-/Trocknungsanlagen.

Ziel-Branchen / Sub-Sektoren:
- Industrielle Bauteilereinigung / Lohnreinigung (Dienstleister + Inhouse-Reinigung)
- Präzisions-Zerspanung / Drehteile / Frästeile (CNC, Automatendreherei)
- Stanz-, Umform- & Feinschneidtechnik (Metallteile, technische Sauberkeit)
- Automotive-Zulieferer (Einspritz-, Antriebs-, Bremsen-, E-Mobility-Komponenten)
- Medizintechnik / Implantate / chirurgische Instrumente (Reinraum, hygienischer Transport)
- Hydraulik / Pneumatik / Ventiltechnik
- Wälzlager / Antriebs- & Lineartechnik
- Oberflächentechnik / Galvanik / Wärmebehandlung (Teile auf Trägern)
- Feinmechanik / Optik / Sensorik / Elektronikkomponenten
- Hersteller von Bauteilreinigungsanlagen (OEM/Partner – Träger-Integration)

Firmengröße: ~50–2000 MA, produzierender Mittelstand mit eigener Fertigung/Reinigung.

Region / Land: DACH-Schwerpunkt (DE, AT, CH), Kern Baden-Württemberg/Bayern.

Bedarfs-Signale:
- eigene Bauteilreinigungsanlage / „technische Sauberkeit“ / „Restschmutzanalyse“
- Reinraumfertigung / ISO-Klasse / Medizinprodukte (ISO 13485)
- Präzisionsteile, die geschützt transportiert/gelagert werden müssen
- Automotive-Sauberkeitsvorgaben (VDA 19 / ISO 16232)
- Edelstahl-/Stahlteile in Serie, Reinigungskörbe/Werkstückträger im Einsatz

Ausschlusskriterien:
- reine Händler/Distributoren ohne Fertigung
- Branchen ohne Teilesauberkeits-/Trägerbedarf (Software, Dienstleistung, Bau, Food-Retail)
- Kleinstbetriebe ohne Serienfertigung
- Hersteller konkurrierender Werkstückträger/Reinigungskorb-Systeme
